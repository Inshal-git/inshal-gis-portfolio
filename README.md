# Inshal Khan | GIS Portfolio

A personal portfolio presenting GIS, remote-sensing and spatial-data projects, with original maps, History Lens app screenshots and course certificates.

## Stack
React, Vite, GSAP and Framer Motion.

## Run locally
```sh
npm ci
npm run dev
```
Open the local URL printed by Vite.

## Production build
```sh
npm run build
npm run preview
```

## Features
- Pull-cord light/dark theme switch with local preference storage
- Project maps and keyboard-accessible full-size image galleries
- History Lens poster download
- CV and training certificate downloads
- Contact dialog, responsive layouts and reduced-motion support

## Project evidence
The OSM comparison figure reports project-specific model accuracies. Captions identify missing evaluation details; the values are not presented as independently verified or generalised performance. Concept SVGs are labelled separately from project outputs.
